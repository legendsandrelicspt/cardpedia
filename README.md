# Cardpedia

A responsive marketplace for buying, selling and trading collectible cards and sealed products across Europe.

## Run locally

Open `index.html` in a browser or serve the folder with any static HTTP server.

## Features

- Search, game/condition/price filters, and price sorting.
- Favourites and basket with quantity and subtotal updates.
- Listing form for items for sale or trade.
- Sale/trade safety checklist and local-only previews for buyer support, trade proposals and issue reports.
- Responsive English-language interface with euro pricing.

All transaction and mediation screens are prototype-only. No payment is held, no seller is contacted and no support case is submitted. Real buyer protection requires a backend, secure messaging, identity and dispute operations, and a compliant payment provider; the current prototype is not a trustee or escrow service.
